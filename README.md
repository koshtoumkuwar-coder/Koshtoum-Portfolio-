# Koshtoum Portfolio — Enhanced Edition

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive styling, neon glow, animations and light theme
- `script.js` — menu, theme, filters, animated role text, glow tracking and contact form

## Run in VS Code
1. Open this folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html` and choose **Open with Live Server**.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` and `script.js`.
2. Add your actual GitHub and LinkedIn profile URLs.
3. Add real repository links, screenshots and project details.
4. Verify education and internship dates/titles.

The contact form opens the visitor's default email app. It does not send messages through a server.
